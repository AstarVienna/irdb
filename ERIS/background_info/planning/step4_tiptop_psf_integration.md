# Step 4: tiptop_ipy PSF Integration

## Goal
Replace the placeholder `SeeingPSF` effects in the AO mode YAMLs with
wavelength-dependent PSF FITS files generated by tiptop_ipy, loaded via
ScopeSim's `FieldConstantPSF` or `FieldVaryingPSF`.

## Background

### tiptop_ipy
tiptop_ipy is a Python wrapper around TIPTOP (Tool for Integrated Performance
evaluation of Tip-tilt and Optimal PSF) that generates AO-corrected PSF
predictions for various instruments. The ERIS configuration files already exist:
- `D:\Repos\tiptop_ipy\tiptop_ipy\instrument_templates\ERIS.ini` — NGS mode
- `D:\Repos\tiptop_ipy\tiptop_ipy\instrument_templates\ERIS_LGS.ini` — LGS mode

### tiptop_ipy Output Format
The tiptop univie server produces FITS files compatible with ScopeSim's
`FieldVaryingPSF` objects. Each FITS file contains:
- Multiple extensions, one per field position (or one for field-constant)
- Each extension has a 3D data cube: (N_wavelength, N_y, N_x)
- Header keyword `WAVELENG` (or similar) indicates the wavelength of each layer
- Header keywords `CDELT1`/`CDELT2` give the PSF pixel scale in arcsec

### ScopeSim PSF Effects
- `FieldConstantPSF`: Single PSF applied uniformly across the field
  - Expects FITS with wavelength-dependent 2D PSF layers
  - `wave_key` parameter specifies the header keyword for wavelength
- `FieldVaryingPSF`: Position-dependent PSF (anisoplanatism)
  - Expects FITS with multiple extensions, each for a different field position
  - More appropriate for off-axis guide star scenarios

## ERIS AO Modes and PSF Requirements

### NGS Mode
- **On-axis:** Strehl ~80% in K-band for bright guide stars (GRP 1-10)
  tails to ~50% at GRP=13
- **Off-axis:** Performance degrades with distance due to anisoplanatism
  (single DM, finite isoplanatic patch)
- **tiptop config:** 40×40 SH WFS, 1000 Hz, 0.2e- RON, Paranal 10-layer Cn2

For on-axis science (guide star = science target), a `FieldConstantPSF` is sufficient.
For off-axis guiding, `FieldVaryingPSF` would be more accurate but requires
generating PSFs at multiple field positions.

**Recommended:** Start with `FieldConstantPSF` for a grid of guide star
magnitudes and seeing conditions.

### LGS Mode
- **Performance:** Lower Strehl than NGS due to cone effect and tip-tilt residuals
- **Dual loop:** HO from LGS at 1000 Hz, LO from natural star at 500 Hz
- **Tip-tilt star:** Can be up to 59" off-axis (tilt anisoplanatism)
- **tiptop config:** ERIS_LGS.ini with LGS at 90km, 4×4 LO WFS

**Recommended:** `FieldConstantPSF` for standard cases. The LGS cone effect
and tip-tilt residuals are already modelled by tiptop.

### Seeing Enhancer (SE)
- **Performance:** LGS correction without tip-tilt star
- **Result:** Higher-order correction but residual tip-tilt jitter
- **PSF:** Sharper core than natural seeing but with extended halo from tip-tilt

**Recommended:** `FieldConstantPSF`. The SE PSF is qualitatively different from
NGS/LGS — it has a sharp core but larger halo. tiptop can generate this by
setting the LO loop gain to 0 or disabling the LO WFS.

### No-AO Mode
- **Performance:** Natural seeing (0.6-1.2" typical at Paranal)
- **PSF:** Gaussian/Moffat seeing disk

**Recommended:** Keep using `SeeingPSF` — no need for tiptop here.

## Implementation Plan

### 4.1 — Generate PSF FITS Files

Use tiptop_ipy to generate wavelength-dependent PSF cubes for:

| File | AO Mode | Guide Star | Seeing | Wavelengths |
|------|---------|-----------|--------|-------------|
| `PSF_NGS_bright_08see.fits` | NGS | GRP=8 | 0.8" | J, H, K, L, M band centers |
| `PSF_NGS_faint_12see.fits` | NGS | GRP=12 | 0.8" | J, H, K |
| `PSF_LGS_default_08see.fits` | LGS | TT at GRP=14 | 0.8" | J, H, K, L, M |
| `PSF_SE_default_08see.fits` | SE | none | 0.8" | J, H, K |

Each FITS file should have:
- ~5-10 wavelength layers spanning the relevant band
- PSF pixel scale matching or finer than the instrument pixel scale (≤13mas)
- Sufficient PSF size to capture the wings (at least 2-3" radius)

**Script needed:** A Python script that:
1. Loads the ERIS.ini / ERIS_LGS.ini templates
2. Modifies parameters (guide star magnitude, seeing, wavelength)
3. Runs tiptop_ipy to generate PSFs
4. Packages the results into ScopeSim-compatible FITS format

### 4.2 — Update AO Mode YAMLs

Replace `SeeingPSF` with `FieldConstantPSF`:

```yaml
# ERIS_AO_NGS.yaml
effects:
  - name: eris_ao_psf
    description: NGS AO PSF from tiptop_ipy
    class: FieldConstantPSF
    kwargs:
      filename: "psfs/PSF_NGS_bright_08see.fits"
      wave_key: "WAVELENG"
```

The PSF file can be selected via OBS properties:
```yaml
# In default.yaml mode_yamls:
properties:
  psf_file: "psfs/PSF_NGS_bright_08see.fits"

# In ERIS_AO_NGS.yaml:
effects:
  - name: eris_ao_psf
    class: FieldConstantPSF
    kwargs:
      filename: "!OBS.psf_file"
      wave_key: "WAVELENG"
```

### 4.3 — Handle VLT Generic PSF Interaction

Currently both the VLT generic PSF and the AO PSF are applied (double-convolution).
For the tiptop PSFs which already include diffraction:

**Option A:** Disable VLT generic PSF in the AO YAML
- Problem: `FieldConstantPSF` with `include: false` still fails if no `filename`
- Solution: Set `filename` to the same tiptop file but with `include: false`
  (ScopeSim may still try to load it — needs testing)

**Option B:** Remove VLT PSF from the YAML chain
- In the AO mode_yamls, replace `VLT.yaml` with a custom `ERIS_VLT.yaml` that
  omits the `vlt_generic_psf` effect but keeps the mirror list

**Option C (simplest):** Accept double-convolution
- The VLT poppy PSF is a ~50mas Airy pattern at K-band
- The tiptop PSF already includes diffraction effects
- Double-convolution slightly broadens the PSF (~5-10% at K)
- This is acceptable for the skeleton package

**Recommended:** Option B for accuracy. Create `ERIS_VLT.yaml`:
```yaml
object: instrument
alias: TEL
name: VLT
description: VLT UT4 for ERIS (without generic PSF — AO provides the PSF)

properties:
  temperature: "!ATMO.temperature"

effects:
  - name: vlt_mirror_list
    class: SurfaceList
    kwargs:
      filename: LIST_VLT_mirrors.dat
```

Then in the AO mode_yamls, use `ERIS_VLT.yaml` instead of `VLT.yaml`.

### 4.4 — Validation

- Compare tiptop PSF Strehl ratio at K-band against ERIS specs:
  - NGS bright (GRP<10): Strehl ~80%
  - NGS faint (GRP~13): Strehl ~50%
  - LGS: Strehl ~50-60% K-band
- Compare FWHM: diffraction limit at K=56mas, at J=33mas
- Verify that the PSF varies correctly with wavelength (better correction at longer λ)
- Run star-field simulation and check photometry
